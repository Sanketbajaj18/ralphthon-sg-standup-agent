# Ralphthon @SG · The Standup Agent

My harness stack for Ralphthon Singapore (17 May 2026).

**Base harness:** [oh-my-codex](https://github.com/Yeachan-Heo/oh-my-codex) by @Yeachan-Heo

**Frameworks:** Codex (primary), Claude Code (secondary), Openclaw

**What I'm building:** The Standup Agent. A CLI agent that watches your git history, calendar, and Slack from the last 24 hours, then generates a 3-line standup in your voice every morning. Built as a custom OMX skill running `$ralph` mode for self-correction.

**Why:** Standups are the most attended meeting in remote work and also the most dead. If autonomous agents can't replace a standup, what can they replace?
